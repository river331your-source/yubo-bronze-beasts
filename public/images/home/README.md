# 主页分层素材

将以下 PNG 放入此目录，页面会自动引用。缺失时暂用占位/回退图。

| 文件名 | 用途 | 回退 |
|--------|------|------|
| `bg-taotie.png` | ② 兽面纹背景 | `/images/网页背景.png` |
| `bg-starmap.png` | ③ 星图装饰 | 径向渐变占位 |
| `seal.png` | ⑤ 印章 | 缺失时不显示（无占位） |

根目录 `/public/images/` 还需：

| 文件名 | 用途 | 回退 |
|--------|------|------|
| `title.png` | ④ 主标题 | `/images/preview.webp` |
